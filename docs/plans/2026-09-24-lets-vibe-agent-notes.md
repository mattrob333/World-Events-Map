- Jev does not stream; answers in one piece (pydantic.dev/docs/ai/models/typesafe). Question types noul/choice(<=255)/score(2-10) (docs.typesafe.ai/api.md).
- "Streaming UI + Jev" = Vercel Labs json-render + experimental Jev composer (PR #342, experimental_composeSpec): app supplies component candidates; Jev picks tree/grouping/order in 2 batched evals; streams spec snapshots. Chris Tate X post "json-render + jev... instant". Demo travel-ticket UI 0.88s Jev vs 3.68s LLM (vendor claims).
- ANGULARarchitects flight assistant: Jev 107-204ms vs LLM 0.7-2.6s (outlier 13s). Pair Jev with lean LLM for extraction.
- jevsearch: local keyword pass streams hits, then top 20 to Jev for rerank.
- AI SDK experimental_evaluate (ai>=7.0.105), model typesafe-ai/jev via AI Gateway; 64k tokens/request; $0.042/1M input tokens, output free.
- Recommended transport: AI SDK UI message stream (createUIMessageStream, typed data parts data-transit/data-stay/data-dining/data-activity/data-show, same id updates in place) or hand-rolled SSE with same shape. Avoid RSC streamUI. json-render composer experimental.
